# WebGuard

WebGuard is a small, privacy-first web-safety dashboard for everyday security habits.

## Run locally

Open `index.html` in a modern browser. No build step, account, or server is required.

## Included

- An interactive safety checklist whose progress is kept only for the current page visit.
- A URL format review that runs locally and does not visit the URL.
- A basic password-strength guide that runs locally. It is not a password auditor; use a sample rather than a password you currently use.
- Responsive layout and keyboard-accessible controls.

## Privacy and limitations

WebGuard does not send input to a server or save it between visits. The link review only reports visible URL characteristics; it cannot tell whether a website is safe, legitimate, or free of malware. The password guide is educational and cannot guarantee password security.
